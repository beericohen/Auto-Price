How the estimate is made

A multilayer perceptron reads 14 details about a car and outputs one number: its expected price in the Israeli used-car market.

Measured against the training data itself, not a separate held-out test set — treat these as a sense of fit, not an independent benchmark.

What it doesn't know: accident history, service records, cosmetic condition, or how motivated the seller is to negotiate. It only sees the fields in the form above, learned from — input features across — listings.
01
Input layer — 84 features
Manufacturer, model, trim, fuel, transmission and drive type (one-hot encoded), plus year, ownership count, mileage, engine size and horsepower (scaled 0–1).
02
Hidden layer — 64 neurons, ReLU
Combines the raw inputs into broader patterns — the rough shape of "recent, low-mileage, high-trim" versus "older, high-mileage, base trim."
03
Hidden layer — 32 neurons, ReLU
Refines those patterns further before they're reduced to a single value.
04
Output — 1 value
A single predicted price, scaled back into shekels.
